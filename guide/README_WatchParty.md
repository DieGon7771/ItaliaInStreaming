# 🎬 WatchParty – Setup and Usage Guide


WatchParty is a CloudStream extension that allows multiple users to watch the same content together while keeping playback synchronized across their devices. **It was the first Watch Party plugin created for CloudStream 🥇**


It includes synchronized playback, real-time chat, and host controls for managing participants in a room. WatchParty is also compatible with **Nuvio Enhanced**, allowing CloudStream and Nuvio Enhanced users to watch together in the same room.


## 📥 Installation


1. Add the **DieGon repository (ItaliaInStreaming)**.
2. Install the **WatchParty** extension.
3. The first time you use WatchParty, you'll be asked to accept the Terms and Privacy Notice.
4. Open a movie or episode to get started.


## 🎮 How to Use


1. Open the same movie or episode on all devices.
2. In the player, tap the icon in the bottom-right corner to open the WatchParty settings.
3. One user creates a room and shares the **6-digit room code** with the other participants.
4. The other users enter the code to join the room.


**Each room supports up to 5 users, including the host.**


The chat icon is located on the left side of the player. Tap it to open the chat panel and send messages without leaving the player.


> **Note:** On some devices, the chat icon may overlap with the camera cutout or notch. You can change its position in Advanced Settings.


## ✨ Features


### 🔄 Synchronized Playback


Playback actions are synchronized between all participants in real time.


- Play and pause
- Seeking
- Changing episodes


All actions are automatically synced across devices, so there's no need to manually synchronize playback.


### 💬 Real-Time Chat


Chat with other participants directly inside the player without interrupting playback.


- Send and receive messages in real time
- Get notified when someone joins or leaves the room
- Track unread messages
- Adjust the chat panel size in the settings


### 👑 Host Controls


The host can manage which actions guests are allowed to perform.


- Enable or restrict play/pause
- Enable or restrict seeking
- Enable or restrict changing to the next episode
- Remove participants using the red **X** button
- Lock the room to prevent new users from joining
- Promote a guest to host by holding their name in the participant list


Promoting a guest allows control of the room to be transferred to another participant.


### 🔁 Resync Now


If playback gets out of sync, use **Resync Now** to synchronize everyone again.


It restores the same playback position for all participants and resumes playback together, without requiring anyone to adjust their position manually.


### 📱 Nuvio Enhanced Support


WatchParty is also compatible with **Nuvio Enhanced**, allowing CloudStream and Nuvio Enhanced users to watch together in the same room.


## 🔐 Terms and Privacy Notice


Before using WatchParty for the first time, you must accept the Terms and Privacy Notice displayed by the extension.


The relay server is used only to transmit real-time playback commands, such as play, pause, and seek, chat messages, and the room PIN between connected devices.


- Audio and video streams **never pass through the relay server**.
- Media is loaded directly on each user's device.
- Data handled by the relay server is processed in memory for real-time routing.
- No chat history, logs, or personal data are recorded or stored on the server.
- Once delivered, messages leave no trace on the server.
